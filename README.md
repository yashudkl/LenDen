# LenDen
# लेनदेन (LenDen)

**A simple way to keep track of money you owe and money others owe you.**

LenDen is a personal lending and borrowing tracker built with React. It helps users keep track of their transactions, manage debts, and understand how much money they owe or are owed by others.

The project is currently focused on frontend development, with plans to integrate Appwrite as the backend in the future.

##  Features

### Current Features
- Track money lent to other people.
- Track money borrowed from other people.
- View total money lent and borrowed.
- Maintain individual transaction records.
- Navigate between different sections using React Router DOM.
- Manage application state using Redux Toolkit.

### Planned Features
- User authentication with Appwrite.
- Cloud database integration.
- Persistent transaction history.
- Add, edit, and delete transactions.
- Track repayment status.
- Individual profiles for people involved in transactions.
- Transaction history and summaries.

##  Tech Stack

| Technology | Purpose |
|---|---|
| React | Frontend UI |
| JavaScript | Application logic |
| Redux Toolkit | Global state management |
| React Router DOM | Client-side routing |
| Tailwind CSS | Styling |
| Appwrite (Planned) | Backend, authentication and database |

## Project Goal

The goal of LenDen is to build a practical application while exploring modern React development concepts, particularly global state management with Redux Toolkit and client-side navigation with React Router DOM.

This is an ongoing learning project, and new features will be introduced as development progresses.
